作者: aotan083
日付: 2026-11-05
版: 1.0

## 1. 概要とクラス

指定したフォルダー（`RootPath`）を根にして、フォルダーとファイルを1本のツリーに並べる部品です。VS Code のエクスプローラーのように使えます。TCListView は要りません。フォームに置いて開き先の部品をつなぐだけで、コピー・切取り・貼付け・削除・名前の変更・フォルダー作成・ドラッグ＆ドロップ・右クリックメニュー・ダブルクリックで開く、が動きます。

```
v data
    v dir1
        inner.txt
    > dir2
    > dir10
      a.txt
      b.txt
      sample.url
      日本語.txt
```

- 根のフォルダーが最上位の1項目になる。根より上のフォルダーへは移動できない（上を見たいときは `RootPath` を変える）。
- フォルダー、ファイルの順に並ぶ。それぞれエクスプローラーと同じ自然順（`dir1`、`dir2`、`dir10`）。
- ファイルのアイコンは、拡張子に合わせた Windows のアイコンを出す。
- ダブルクリックで開く。`.url` は TargetBrowser、`.lnk` はリンク先で振り分け、テキストは TargetEditor、それ以外は Windows の関連付け。
- 選んだファイルを TCMonacoEditor・TCsEditor へドロップすると、新しいタブで、ファイルの数だけ開く。
- ほかのアプリやエクスプローラーでフォルダー・ファイルが増減すると、表示が自動で更新される（サブフォルダーの中も）。F5 でも更新できる。

| 項目 | 内容 |
|---|---|
| Lazarus | 4.8 5.0RC1 |
| FPC | 3.2.2 |
| OS | Windows 11（64 ビット） |
| パレット | CX |

### 1.1 クラスとユニット

| クラス | ユニット | パッケージ | 元のクラス | 中身 |
|---|---|---|---|---|
| `TCFileTree` | `CFileTree` | cx | `TCustomTreeView`（LCL） | 指定したフォルダーを根にした、フォルダーとファイルのツリー。操作・ドラッグ＆ドロップ・右クリックメニュー・開く動作が、コードを書かずに動く |

| 型 | ユニット | 中身 |
|---|---|---|
| `TCFileNode` | `CFileTree` | ツリーの項目。`IsDir`（フォルダーなら `True`）を持つ |

- フォームに置くと、uses に `CFileTree` が自動で入る。
- フォームに置くと、プロジェクトの必要パッケージに cx が自動で追加される。
- コードで作るときは、uses に自分で書く（10.7）。

## 2. フォームに置いて動かすまで

### 2.1 ツリーだけを使う

1. パレット [CX] から、TCFileTree をフォームに置く。
2. `RootPath` に、根にするフォルダーを書く（既定値は `C:\`）。
3. 実行する。根のフォルダーが開いた状態で表示される。

### 2.2 エディター・ブラウザーとつなぐ

ダブルクリックや右クリックメニューで開く先を、プロパティで決める。フォームに置いた部品を、オブジェクトインスペクタで選ぶだけで、コードは要らない。

| プロパティ | つなぐ部品 | 開くもの |
|---|---|---|
| `TargetEditor` | TCMonacoEditor または TCsEditor | テキストのファイル（ダブルクリック、「text開く」「text新規タブで開く」） |
| `TargetBrowser` | TCTabBrowser | `.url` の URL、Web で開くもの（ダブルクリック、「Web開く」「Web新規タブで開く」） |
| `SideEditor` | TCMonacoEditor または TCsEditor | 「横に並べて表示」（text） |
| `SideBrowser` | TCTabBrowser | 「横に並べて表示」（Web） |

- 片方だけでもよい。つないでいない開き先の項目は、灰色になる。
- `TargetEditor` と `SideEditor` は、同じ種類のエディターだけをつなげる（TCMonacoEditor と TCsEditor を混ぜる組み合わせは受け付けない。あとから選んだ方が無視される）。
- 「横に並べて表示」は、`SideEditor`・`SideBrowser` に新規タブで開く。その部品が隠れているときは、表示にする。並べる位置は、フォーム上の配置（左右に置く、スプリッターを付ける）で決める。横に開ける部品は、それぞれ1つ。

### 2.3 隠しファイルを出す

1. `ShowHidden` を `True` にする。実行中は、右クリックメニューの「隠しファイルを表示」でも切り替えられる。
2. 隠し・システム属性のファイル・フォルダーが出る。開いている状態と選択は保たれる。

### 2.4 画面の言語（日本語・English）

この部品が画面に出す文字（メニュー・メッセージ）は、日本語か英語で出る。言語は cx の部品すべてで 1 つで、部品ごとには決めない。

EXE と同じフォルダーの WebView2.ini に、次のように書く。WebView2 を使わないアプリでも、この ini を置く（`[CX]` だけを書けばよい）。

```ini
[CX]
Language=en
```

| 順 | 決め方 |
|---|---|
| 1 | `[CX]` の `Language` が `ja` または `en` なら、その言語（大文字・小文字は問わない） |
| 2 | それ以外（ini が無い・`[CX]` が無い・空・ほかの値）は、Windows の表示言語。日本語なら `ja`、それ以外は `en` |

- 最初に文字を出すときに 1 回だけ決める。実行中に書き換えても、次の起動まで効かない。
- この取説に書いた画面の文字は、日本語のときのもの。英語のときは英語（「Copy」「Cut」など）で出る。
- 「windowsメニュー」の中身（送る・プロパティなど）は、Windows の言語で出る。

## 3. ツリーの構成

| 項目 | 内容 |
|---|---|
| 根 | `RootPath` のフォルダー。フォルダー名（ドライブの根は `C:\` のようにパス）を出す。コピー・切取り・削除・名前の変更はできない |
| フォルダー | 先に並ぶ。開くと、中のフォルダー・ファイルを読み込む。中身が空のフォルダーは、開くと開閉の印が消える |
| ファイル | フォルダーの後に並ぶ。開閉の印はない |
| 並び順 | フォルダー → ファイルの順。それぞれエクスプローラーと同じ自然順（数字を数の大きさで比べる） |
| 隠し・システム属性 | 既定では出さない（`ShowHidden`） |

- 根が実在しないとき（`RootPath` が空、または存在しない）は、空のツリーになる。
- まだ開いていないフォルダーの中身は、開いたときに最新を読む。

### 3.1 選択

- 複数選択できる（Ctrl+クリック、Shift+クリック）。ただし、選べるのは**同じフォルダーの中の項目だけ**。別のフォルダーの項目を足そうとすると、前の選択が外れ、新しい項目だけになる（Windows のコピー・移動・削除・ドラッグが、同じフォルダーの中の項目を前提にしているため）。
- 複数選択の中の項目を、修飾キーなしで押してドラッグすると、まとめて動かせる。動かさずに離すと、その1つだけの選択になる。
- 右クリックしたとき、その項目がすでに選択に入っていれば、選択はそのまま。入っていなければ、その項目だけを選ぶ。何もない所を右クリックしたときは、選択をすべて外す。

## 4. プロパティ

### 4.1 この部品で足したもの

| 名前 | 型 | 読み書き | 中身 |
|---|---|---|---|
| `RootPath` | `string` | 読み・書き | 根にするフォルダー（既定値は `C:\`）。書くと、ツリーを作り直す。末尾の `\` は除かれる（ドライブの根 `C:\` は残る）。実在しない・空なら空のツリー |
| `ShowHidden` | `Boolean` | 読み・書き | 隠し・システム属性の項目を出すか（既定値は `False`）。切り替えは、実行中でもすぐに反映される |

| `SideEditor` | `TControl` | 読み・書き | 「横に並べて表示」（text）の開き先のエディター。`TargetEditor` と同じ種類（既定値は nil） |
| `SideBrowser` | `TCTabBrowser` | 読み・書き | 「横に並べて表示」（Web）の開き先のブラウザー（既定値は nil） |

- 開き先の部品が解放されると、そのプロパティは nil になる。

## 6. イベント

この部品で足したイベントはない。使えるものは、次のとおり。

| 名前 | 引数 | 中身 |
|---|---|---|
| `OnClick` | `Sender: TObject` | クリックされた |
| `OnDblClick` | `Sender: TObject` | ダブルクリックされた（開く処理は、部品が先に行う） |
| `OnEnter` | `Sender: TObject` | フォーカスが入った |
| `OnExit` | `Sender: TObject` | フォーカスが出た |
| `OnExpanded` | `Sender: TObject; Node: TTreeNode` | 項目が開いた |
| `OnCollapsed` | `Sender: TObject; Node: TTreeNode` | 項目が閉じた |
| `OnKeyDown` | `Sender: TObject; var Key: Word; Shift: TShiftState` | キーが押された |
| `OnKeyPress` | `Sender: TObject; var Key: Char` | 文字のキーが押された |
| `OnKeyUp` | `Sender: TObject; var Key: Word; Shift: TShiftState` | キーが離された |
| `OnMouseDown` | `Sender: TObject; Button: TMouseButton; Shift: TShiftState; X, Y: Integer` | マウスのボタンが押された |
| `OnMouseMove` | `Sender: TObject; Shift: TShiftState; X, Y: Integer` | マウスが動いた |
| `OnMouseUp` | `Sender: TObject; Button: TMouseButton; Shift: TShiftState; X, Y: Integer` | マウスのボタンが離された |
| `OnMouseWheel` | `Sender: TObject; Shift: TShiftState; WheelDelta: Integer; MousePos: TPoint; var Handled: Boolean` | ホイールが回された |
| `OnSelectionChanged` | `Sender: TObject` | 選択が変わった |

- 開く・横に並べて表示する処理を、アプリのコードで動かすためのイベントはない。開き先は、プロパティ（2.2）で決める。
- ファイル・フォルダーのコピー・移動・削除・名前の変更・作成を知らせるイベントはない。表示は部品が自動で更新する。
- 部品が使っているキー（Ctrl+C・Ctrl+X・Ctrl+V・Delete・Shift+Delete・F2・F5・Enter）を、`OnKeyDown` やフォームの `OnKeyDown`（`KeyPreview = True`）で `Key := 0` にすると、部品の動作が止まる。

## 7. 操作

### 7.1 キー

| キー | 動作 |
|---|---|
| Ctrl+C | 選んでいる項目をコピー（根は対象外） |
| Ctrl+X | 選んでいる項目を切り取り（根は対象外） |
| Ctrl+V | 貼り付け（先は、選んでいるフォルダー。ファイルを選んでいるときはその親） |
| Delete | ごみ箱へ移動（確認あり。根は対象外） |
| Shift+Delete | 完全に削除（確認あり） |
| F2 | 名前の変更（根は対象外） |
| F5 | 開いているフォルダーをすべて最新の状態に更新 |
| Enter | 選んでいるファイルを開く（ダブルクリックと同じ）。フォルダーは開閉 |

### 7.2 ダブルクリック・Enter で開く

| ファイル | 動き |
|---|---|
| フォルダー | 開く／閉じる |
| `.url` | 中の URL を、`TargetBrowser` の表示中のタブで開く。`TargetBrowser` がなければ、Windows の関連付けで開く |
| `.lnk` | リンク先を見る。`http://`・`https://` なら `TargetBrowser`、テキストのファイルなら `TargetEditor` の表示中のタブ、それ以外は `.lnk` を Windows の関連付けで開く |
| テキストのファイル | `TargetEditor` の表示中のタブで開く。`TargetEditor` がなければ、Windows の関連付けで開く |
| それ以外のファイル | Windows の関連付けで開く |

- 「テキストのファイル」かどうかは、ファイルの先頭 8KB を見て決める。空のファイル、UTF-16 の BOM で始まるファイルはテキスト。NUL（0x00）が1つでもあればテキストではない。拡張子の一覧は使わない。
- `TargetEditor` の表示中のタブで開くときの動きは、TCBookmark と同じ。そのファイルをすでに開いているタブがあれば、そのタブに切り替える。表示中のタブに未保存の変更があれば、新しいタブで開くかを聞く（いいえなら開かない）。ほかは、表示中のタブに読み込む。
- ファイルがなくなっていたときは、メッセージを出して開かない。

### 7.3 右クリックメニュー

マウスの下の項目を選んでから出る（7.1 の選択の決まりは 3.1）。メニューは、部品が持っている（`PopupMenu` は使えない）。

| 順 | 項目 | 動き | 使えるとき |
|---|---|---|---|
| 1 | コピー | 7.1 の Ctrl+C | 項目を選んでいて、根を含まない |
| 2 | 切取り | 7.1 の Ctrl+X | 同上 |
| 3 | 貼付け | 7.1 の Ctrl+V | クリップボードにファイルがある |
| 4 | 名前の変更 | 7.1 の F2 | 1つだけ選んでいて、根でない |
| 5 | 削除 | ごみ箱へ（確認あり） | 項目を選んでいて、根を含まない |
| | （区切り線） | | |
| 6 | エクスプローラーで表示 | フォルダーなら、そのフォルダーをエクスプローラーで開く。ファイルなら、そのファイルを選んだ状態でエクスプローラーを開く | 項目を選んでいる |
| 7 | パスのコピー | 選んでいる項目のフルパスを、クリップボードへ（複数なら1行に1つ） | 項目を選んでいる |
| | （区切り線） | | |
| 8 | フォルダ作成 | `NewFolder`（5章） | いつでも |
| | （区切り線） | | |
| 9 | text開く | `TargetEditor` の表示中のタブで開く（7.2 と同じ） | ファイルを1つ選んでいて、テキスト、`TargetEditor` がある |
| 10 | text新規タブで開く | `TargetEditor` の新規タブで開く | 同上 |
| 11 | 横に並べて表示 | `SideEditor` の新規タブで開く（`SideEditor` が隠れていれば表示にする） | ファイルを1つ選んでいて、テキスト、`SideEditor` がある |
| | （区切り線） | | |
| 12 | Web開く | `TargetBrowser` の表示中のタブで開く | ファイルを1つ選んでいて、Web で開けるもの、`TargetBrowser` がある |
| 13 | Web新規タブで開く | `TargetBrowser` の新規タブで開く | 同上 |
| 14 | 横に並べて表示 | `SideBrowser` の新規タブで開く（隠れていれば表示にする） | ファイルを1つ選んでいて、Web で開けるもの、`SideBrowser` がある |
| | （区切り線） | | |
| 15 | プログラムで開く | Windows の関連付けのプログラムで開く | ファイルを1つ選んでいる |
| | （区切り線） | | |
| 16 | 隠しファイルを表示 | `ShowHidden` を切り替える（チェック付き） | いつでも |
| | （区切り線） | | |

- 「text開く」系は、テキストのファイル（7.2）だけ使える。`.lnk` は、リンク先がテキストのときだけ。`.url` は使えない。
- 「Web開く」系で開く URL：`.url` は中の URL。`.lnk` はリンク先が `http://`・`https://` のときだけ。ほかのファイルは `file:///` のアドレス（開けるかどうかは WebView2 が決める）。
- 使えない項目は灰色になる。

### 7.4 windowsメニュー

「windowsメニュー」を押すと、エクスプローラーでその項目を右クリックしたときと同じメニューが出る。

- フォルダーとファイルで、中身が違う（ファイルは「開く」「メモ帳で編集」「プログラムから開く」など、フォルダーは「開く」「クイック アクセスにピン留めする」など）。Git・VLC・TortoiseGit など、PC に登録されたアプリの項目も出る。
- 「送る」の中身も出て、選んだ項目を送れる。複数選択のときは、まとめて送る。
- フォルダーを1つ選んでいるとき（根も）は、「新規作成」（フォルダー・ショートカット・テキスト ドキュメントなど）も出る。作るものは、選んだフォルダーの中にできる。
- Windows 11 の短いメニュー（上にアイコンが並ぶもの）ではなく、従来の完全なメニューが出る。
- 「名前の変更」を選ぶと、F2 と同じ名前の変更が始まる。
- メニューから起動するアプリには、エクスプローラーと同じく、項目があるフォルダーが作業フォルダーとして渡される。

### 7.5 ドラッグ＆ドロップ

| 項目 | 動作 |
|---|---|
| 相手 | アプリ内（ツリーの中、ほかの部品）、エクスプローラー・デスクトップ・ほかのアプリと双方向 |
| ドラッグの開始 | ファイル・フォルダーの上でボタンを押し、少し動かす。複数選択していれば、まとめて動かす。根は動かせない |
| コピーか移動か | エクスプローラーと同じ。同じドライブなら移動、別のドライブならコピー。Ctrl でコピー、Shift で移動、Alt でショートカットを作る |
| 右ボタンでドラッグ | ドロップしたときにメニュー（ここにコピー、ここに移動、ショートカットを作成など）を出す |
| ドロップ先 | フォルダーの上なら、そのフォルダーの中。ファイルの上なら、そのファイルがあるフォルダーの中。何もない所なら、根の中 |
| できない操作 | 自分自身・自分の中のフォルダーへのドロップ、同じフォルダーへの移動 |
| ドラッグ中 | ドロップ先のフォルダーを枠で強調、上下の端で自動スクロール、0.7 秒止めると自動で開く |
| 取りやめ | Esc |

コピー・移動・上書きの確認・進み具合の表示は、エクスプローラーと同じく Windows が行う。

#### エディターへのドロップ

- 選んだファイルを TCMonacoEditor・TCsEditor へドロップすると、エディター側の動きで、新しいタブで開く。複数選択していれば、ファイルの数だけ開く。すでに開いているファイルは、そのタブに切り替える。
- フォルダーは何もしない（ファイルだけ開く）。
- 開くだけで、元のファイルは動かない。
- エディターの `OpenDroppedFiles` を `False` にするか、`OnFileDrop` で `Handled := True` にすると、この動きを止められる。

## 8. 自動更新

- ほかのアプリやエクスプローラーでファイル・フォルダーが追加・削除・名前変更されると、表示が自動で更新される。サブフォルダーの中の変更も含む。開いている状態と選択は保たれる。
- エディターの「名前を付けて保存」で、開いているフォルダーにファイルを作った場合も、表示される。
- 更新の対象は、ツリーに読み込み済み（一度でも開いた）のフォルダー。読み込んでいないフォルダーは、開いたときに最新を読む。
- 根の外の変更は、表示に影響しない。
- ネットワークなど、変更が届きにくい場所は、F5（`RefreshTree`）で更新する。
- 選んでいた項目が消えた場合は、LCL の決まりで、近くの項目に選択が移る。
- 根のフォルダーが消えた場合は、空のツリーになる。根を作り直したときは、`RootPath` に一度別のパスを書いてから、元のパスに戻す（同じパスを書いても、何も起きない）。
- 名前の変更中・ドラッグ中は、終わるまで更新を待つ。

## 9. 注意

- 既定の根は `C:\` で、ドライブ全体が対象になる。深い階層まで開くと、読み込みに時間がかかることがある。通常は、作業するフォルダーを `RootPath` に指定する。
- フォルダーを開くときは、そのフォルダーの中身を一括で読む。ファイルが数万件あるフォルダーは、開くのに時間がかかる。
- 同じフォルダーの中の項目だけ、同時に選べる（3.1）。
- 名前の変更で、`\ / : * ? " < > |` を含む名前は付けられない。メッセージが出て、元の名前に戻る。
- ファイル・フォルダーのコピー・移動・削除・名前の変更・作成は、すべて Windows（シェル）が行う。使用中のファイルなどで失敗したときは、Windows が理由を出す。

## 10. 使い方の例

### 10.1 エディターとつなぐ

1. TCFileTree と TCMonacoEditor をフォームに置く。
2. TCFileTree の `TargetEditor` に TCMonacoEditor を選ぶ。
3. `RootPath` に、作業するフォルダーを書く。
4. 実行して、テキストのファイルをダブルクリックする。エディターで開く。

### 10.2 エディターとブラウザーの両方とつなぐ

1. TCFileTree・TCMonacoEditor・TCTabBrowser をフォームに置く。
2. `TargetEditor` に TCMonacoEditor、`TargetBrowser` に TCTabBrowser を選ぶ。
3. `.url` をダブルクリックすると TCTabBrowser で開く。

### 10.3 横に並べて表示する

1. 開き先とは別に、もう1つ TCMonacoEditor をフォームに置く（右側など）。
2. その TCMonacoEditor を、`SideEditor` に選ぶ。
3. ファイルを右クリックして「横に並べて表示」を選ぶと、そのエディターの新規タブで開く。

### 10.4 選んだファイルのパスを取る

```pascal
procedure TForm1.Button1Click(Sender: TObject);
var
  L: TStringList;
begin
  L := TStringList.Create;
  try
    CFileTree1.GetSelectedPaths(L);   // 選んでいる項目すべてのフルパス
    ShowMessage(L.Text);
  finally
    L.Free;
  end;
end;
```

### 10.5 フォルダーを切り替える

```pascal
CFileTree1.RootPath := 'D:\work\project1';   // ツリーを作り直す
```

### 10.6 画面の更新と隠しファイル

```pascal
CFileTree1.RefreshTree;               // F5 と同じ
CFileTree1.ShowHidden := True;        // 隠しファイルも出す
```

### 10.7 コードで作る

```pascal
uses CFileTree, uCmonacos;

var
  Tree: TCFileTree;
  Ed: TCMonacoEditor;
begin
  Ed := TCMonacoEditor.Create(Self);
  Ed.Parent := Self;
  Ed.Align := alClient;

  Tree := TCFileTree.Create(Self);
  Tree.Parent := Self;
  Tree.Align := alLeft;
  Tree.Width := 300;
  Tree.RootPath := 'C:\work';
  Tree.TargetEditor := Ed;
end;
```
